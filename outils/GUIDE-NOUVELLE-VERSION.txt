PASSER À UNE NOUVELLE VERSION DU JEU (ex. 0.35)
===============================================
1. Récupérer le code source de la nouvelle version (git checkout de l'étiquette 0.35).
2. python3 outils/extraire_source.py  .../crawl-ref/source  extraction_0.35.json
3. python3 outils/comparer_versions.py  extraction_0.34.json  extraction_0.35.json  a_traduire.txt
4. Traduire ce qui est dans a_traduire.txt :
   - une description (NOUVEAU / MODIFIÉ) -> ajouter "texte anglais sans retour à la ligne": "traduction", dans
     un fichier de donnees/ (par exemple donnees/interface/complements.js). Un texte MODIFIÉ garde son ancienne
     traduction tant qu'on n'a pas mis à jour la clé : repérer la ligne et corriger.
   - un message à trous (NOUVEAU MESSAGE) -> ajouter une ligne dans donnees/messages/variables_*.js (voir le mode d'emploi
     en tête de variables.js).
5. node outils/couverture.js extraction_0.35.json  : vérifier que le pourcentage remonte.
6. Mettre à jour "version" dans manifest.json et noter les changements dans HISTORIQUE.txt.
Astuce : le dossier dat/descript/fr du dépôt contient la traduction communautaire officielle ; elle est souvent en retard
d'une version, mais utile comme point de départ (moteur d'import : voir l'historique, "officiel.js").
